# Prompts

個人常用 LLM prompt 收藏庫。依用途分類，檔名採英文 kebab-case。

## 目錄

| 分類 | Prompt | 用途 |
|---|---|---|
| `news/` | [finance-news.md](news/finance-news.md) | 全球財經報告（預設每日）：蒐集、查證、分析市場與總體經濟資訊，時間基準 UTC+8。 |
| `news/` | [world-news.md](news/world-news.md) | 全球國際新聞報告（預設每日）：政治、軍事、經濟、科技、能源等領域的整理與研判。 |
| `summary/` | [adhd-friendly-summary.md](summary/adhd-friendly-summary.md) | ADHD 友善精簡摘要：將文章、影片、PDF 或逐字稿濃縮成易讀重點。 |
| `summary/` | [youtube-summary.md](summary/youtube-summary.md) | YouTube 影片知識整理：把口語內容轉成結構化繁中筆記。 |
| `learning/` | [topic-deep-dive.md](learning/topic-deep-dive.md) | 素材驅動的深度研究：從一份素材出發，建立對整個領域的系統性理解。 |

## 命名規則

- 目錄：依用途分類，單數小寫（`news`、`summary`、`learning`）。
- 檔案：英文 kebab-case，名稱需能單獨辨識用途。
